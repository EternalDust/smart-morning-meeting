# 大数据分析 V2 设计

## 目标

用 Hadoop + Spark 做有实际价值的分析，而非 SQL 可替代的简单聚合。

## 数据生成

Python 脚本生成半年 120 场晨会模拟数据（每工作日一场），含早/晚两个时段，签到行为有时段差异。

## 数据链路

```
Python生成 → MySQL → Sqoop → HDFS → Spark分析 → MySQL → 前端
```

## 分析场景

- 周度/月度出勤趋势
- 科室异常检测（Z-score）
- 早班 vs 晚班签到行为对比
- 发言活跃度与出勤率关联

## 前端展示

签到页嵌入趋势卡片，汇报页嵌入异常标记。
