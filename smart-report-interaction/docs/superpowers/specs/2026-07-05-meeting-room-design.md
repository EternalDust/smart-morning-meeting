# 晨会主屏重设计

## 目标

将签到、汇报、互动、分析融合为统一会议界面，参考腾讯会议布局，预留其他子系统接入位。

## 布局

三栏结构 + 顶部信息栏 + 底部功能栏：

- **顶部栏**：会议标题、时间、状态
- **左侧 25%**：议程步骤 + 签到统计 + 质量评分卡片
- **中央 50%**：当前汇报人 + 发言输入 + 汇报记录列表
- **右侧 25%**：互动消息流 + 输入框
- **底部栏**：功能入口（签到、汇报、互动、分析、督办预留、可视化预留）

## 路由

- 新增 `MeetingRoom.vue`（/meeting/:id）
- 旧路由 /sign /report /interaction /analytics 保留，重定向到 /meeting/1

## 组件

会议主屏单文件实现，不拆子组件。从旧页面迁移业务逻辑。

## 接口

沿用现有后端 API，不做后端改动。

## 其他子系统接入位

- 左侧议程区预留审批议程数据接入
- 底部栏预留"督办""可视化"按钮
- 通过 Shell 网关调用其他子系统 API
