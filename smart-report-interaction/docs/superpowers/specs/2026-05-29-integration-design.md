# 五子系统整合 设计文档

日期: 2026-05-29 | 版本: Build1.0

## 目标

一台电脑部署完整项目，前后端分离，局域网可访问，答辩现场流畅演示。

## 架构

```
浏览器 → http://IP:5000
           │
           ├── /login           统一登录页
           └── /home            导航页（5 张子系统入口卡片）
                │
                ├── 大屏 (8080)  ├── 汇报交互 (8081)  ├── 审批议程 (8082)
                ├── 数据采集 (8083)  └── 问题督办 (8084)
```

## 新增

### frontend-shell（Vue3 + ElementPlus）

| 页面 | 功能 |
|------|------|
| `/login` | 工号+密码登录，调用 `/api/auth/login`，token 存 localStorage |
| `/home` | 五张子系统卡片，点进去新标签打开对应子系统前端地址 |

后端登录接口：SpringBoot 轻量应用，端口 5000。查 `sm_gm_members` 验证用户，返回 JWT token。

### sql/init-all.sql

合并五个子系统的 `sql/init.sql`，去掉重复的 CREATE DATABASE 和共享表定义，加演示数据。

演示数据覆盖一次完整晨会场景：会议信息 + 15 个参会人 + 签到记录 + 发言记录 + 交互消息 + 督办问题 + 大屏数据。

## 不碰

五个子系统现有代码不动。各子系统前端 vite proxy 照旧指向自己的后端端口。frontend-shell 通过新标签页跳转，子系统前端页面各自独立渲染。

## 演示流程

1. 执行 `sql/init-all.sql`
2. 依次启动五个后端 + 五个前端 dev server + frontend-shell（共 11 个进程）
3. 浏览器打开 `http://本机IP:5000`
4. 登录 → 导航页 → 依次点击五个子系统演示
